Перевести всех студентов

Студенты перейдут в выбранную группу. Исходная группа будет удалена, поскольку в группе должен оставаться хотя бы один студент.

Добавить студента

Увеличить число студентов в указанной группе на один.

Порядок заполнения

  1. Создайте координаты. Откройте «Координаты» и укажите X и Y.
  2. При необходимости добавьте старосту. Сначала создайте локацию, затем человека в разделе «Старосты».
  3. Добавьте группу. Выберите координаты и старосту, заполните числовые поля, форму обучения и семестр.
  4. Работайте вместе. Другой пользователь может зарегистрироваться и открыть реестр. Изменения появятся автоматически.

Все счётчики и средний балл должны быть больше нуля — в том числе количество отчисленных и переведённых студентов. Это ограничения варианта.

Семестры упорядочены так: FIRST → SECOND → THIRD → FOURTH → EIGHTH. При сортировке строковых колонок используется их строковое представление; специальные операции сравнивают порядок семестров.
